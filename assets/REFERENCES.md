# Varsan-WebDev — Tech / Library References

Libraries and skills to use when building. Collected, not yet installed.

## GitHub libraries
| Library | Repo | Use for |
|---------|------|---------|
| **ShaderGradient** | github.com/ruucm/shadergradient | Animated WebGL gradient backgrounds (hero / section bg). Pairs with R3F. |
| **liquid-logo** | github.com/paper-design/liquid-logo | Liquid/metallic animated logo or name effect (the "S.SRIVARSAN" liquid name → "VARSAN" liquid logo). |
| **liquid-glass-js** | github.com/dashersw/liquid-glass-js | Apple-style liquid-glass / frosted glass UI (buttons, cards, nav). |
| **react-three-fiber** | github.com/pmndrs/react-three-fiber | React renderer for Three.js — base layer for ShaderGradient + 3D hero scene. |

## Claude skills to leverage
- **Emil Kowalski's motion skill** — fixes flat/lifeless output; adds real motion, proper easing, animations that make sense. Use throughout for transitions/reveals.
- **Impeccable** — design-vocabulary skill, ~20 commands (typography, color, spacing, layout). Run **`/polish`** before shipping to tighten the whole UI.
- **Taste Skill** — teaches "what good design looks like." Avoid generic gradients, Inter-on-everything, AI-looking output. Aim for designer-grade interfaces.

## Intent
Build Varsan-WebDev as a premium, motion-rich clone of the varsansri.github.io portfolio — liquid glass + shader gradients + R3F, Pumpkin/Charcoal theme, polished with the design skills above.
